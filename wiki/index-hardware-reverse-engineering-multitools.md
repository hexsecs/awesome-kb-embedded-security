# Hardware Reverse Engineering Multitools

- [Bus Pirate](bus-pirate.md) — Open source hacker multi-tool that talks to electronic stuff. It's got a bunch of features an intrepid hacker might need to prototype their next project.
- [ESP32 Bit Pirate](esp32-bit-pirate.md) — Open-source ESP32 firmware inspired by the Bus Pirate that sniffs and drives I2C, SPI, UART, 1-Wire, JTAG, CAN, and USB from a serial or web-based CLI, with…
- [Glasgow Interface Explorer](glasgow-interface-explorer.md) — Versatile open-source FPGA-based hardware debugging and reverse engineering tool supporting SPI, I2C, UART, JTAG, and custom protocols with a high-level…
- [GreatFET](greatfet.md) — Open-source USB host-side hardware security research platform from Great Scott Gadgets with an expandable neighbor board ecosystem for interfacing with…
- [Hydrabus](hydrabus.md) — Open-source multi-protocol hardware hacking tool with support for SPI, I2C, UART, CAN, 1-Wire, and JTAG interfaces, purpose-built for embedded device analysis.
- [Tigard](tigard.md) — An FTDI FT2232H-based multi-protocol tool for hardware hacking.
