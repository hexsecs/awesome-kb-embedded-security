# Debugging Tools

- [Akheron Proxy](akheron-proxy.md) — Python tool that proxies UART traffic between chips on a board, capturing and replaying inter-chip communications with checksum recalculation.
- [assembly-repl](assembly-repl.md) — Native assembly, LLVM IR, C, C++, and Objective-C REPLs for macOS and Linux.
- [Black Magic Probe](black-magic-probe.md) — An open-source JTAG/SWD debugger with embedded GDB server and automatic target detection.
- [Frida](frida.md) — Dynamic instrumentation toolkit for injecting JavaScript or native code into running processes on embedded Linux, Android, iOS, and bare-metal targets.
- [GDB](gdb.md) — The GNU Project debugger, allows you to see what is going on `inside' another program while it executes -- or what another program was doing at the moment…
- [GEF](gef.md) — Kick-ass set of commands for X86, ARM, MIPS, PowerPC and SPARC to make GDB cool again for exploit dev. It is aimed to be used mostly by exploit developers…
- [Open OCD](open-ocd.md) — Provides on-chip programming and debugging support with a layered architecture of JTAG interface and TAP support.
- [probe-rs](probe-rs.md) — Modern Rust-based embedded debug toolkit supporting SWD/JTAG with built-in flashing, RTT logging, and GDB server for ARM and RISC-V targets.
- [pyOCD](pyocd.md) — An open-source Python library for programming and debugging Arm Cortex-M microcontrollers with cross-platform debug probe support.
