# NFC and RFID

- [libnfc](libnfc.md) — Platform-independent NFC library covering ISO14443-A/B, FeliCa, and MIFARE, and the foundation most other NFC tooling builds on.
- [MFCUK](mfcuk.md) — Implementation of the Dark Side attack, recovering a first MIFARE Classic key when none is known.
- [MFOC](mfoc.md) — Nested attack that recovers the remaining MIFARE Classic sector keys once one key is known; pairs with MFCUK.
- [mfoc-hardnested](mfoc-hardnested.md) — Fork of MFOC adding the hardnested attack, which recovers MIFARE Classic keys from cards with hardened PRNGs that the offline nested attack alone cannot…
- [MifareClassicTool](mifareclassictool.md) — Android app for reading, writing, and analysing MIFARE Classic RFID tags.
