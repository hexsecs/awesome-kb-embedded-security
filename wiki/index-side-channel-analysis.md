# Side-Channel Analysis

- [ChipWhisperer](chipwhisperer.md) — An open-source toolchain for side-channel power analysis and fault injection attacks with complete hardware and software stack.
- [Daredevil](daredevil.md) — Multi-core correlation power analysis tool supporting higher-order attacks, part of the SideChannelMarvels toolset.
- [Jlsca](jlsca.md) — Side-channel analysis toolkit in Julia, geared toward correlation and linear regression attacks over large trace sets.

- [pyecsca](pyecsca.md) — Side-channel analysis and reverse engineering toolkit aimed specifically at elliptic curve implementations, where the other tools here are oriented toward AES.

- [SCALE](scale.md) — Side-Channel Attack Lab Exercises providing educational material for learning power analysis attacks with low-cost hardware.
