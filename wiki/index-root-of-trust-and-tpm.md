# Root of Trust and TPM

- [AMD fTPM Security Guidance](amd-ftpm-security-guidance.md) — AMD guidance and security bulletin coverage related to firmware TPM behavior on supported platforms.
- [Caliptra](caliptra.md) — Apache-2.0 silicon root of trust block for datacenter CPUs, GPUs, and DPUs providing DICE identity, measured boot, and attestation; maintained under CHIPS…
- [IBM Software TPM](ibm-software-tpm.md) — Software TPM 2.0 emulator for testing and development.
- [Keylime](keylime.md) — Open source TPM-based remote attestation for cloud and edge.
- [OpenSK](opensk.md) — Open-source FIDO2 security key firmware in Rust for embedded targets, implementing the U2F and FIDO2 authenticator standards.
- [OpenTitan](opentitan.md) — Open-source silicon root of trust project with security-certified hardware designs and commercial-grade IP blocks.
- [TPM 2.0 Reference Implementation](tpm-2-0-reference-implementation.md) — TPM 2.0 specification and reference software from the TCG.
- [tpm2-algtest](tpm2-algtest.md) — Tests real TPM 2.0 chips for RNG output quality, key generation timing, algorithm support, and implementation fingerprints across 80+ firmware revisions…
- [tpm2-tss](tpm2-tss.md) — Reference implementation of the TCG TPM2 Software Stack (TSS2), providing the APIs for key management and attestation.
- [TPMGenie](tpmgenie.md) — I2C bus interposer for discrete TPMs that intercepts and modifies TPM traffic for vulnerability research.
- [wolfTPM](wolftpm.md) — Portable TPM 2.0 library designed for embedded use, supporting SPI and I2C TPMs plus a firmware TPM option.
