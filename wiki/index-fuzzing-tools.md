# Fuzzing Tools

- [AFL++](afl.md) — A coverage-guided fuzzer with enhanced mutations, QEMU and Unicorn emulation modes, and custom power schedules.
- [boofuzz](boofuzz.md) — Actively maintained network protocol fuzzer and the spiritual successor to Sulley, with session management, target monitoring, and protocol graph support.
- [Fuzzowski](fuzzowski.md) — A network protocol fuzzer based on the Sulley/BooFuzz framework with support for TCP/UDP/SSL protocols.
- [GDBFuzz](gdbfuzz.md) — Uses GDB hardware breakpoints as a coverage source for uninstrumented embedded targets — works on any GDB-debuggable MCU with no firmware modification…
- [honggfuzz](honggfuzz.md) — A feedback-driven evolutionary fuzzer supporting hardware-based coverage (Intel BTS/PT) and persistent mode for extreme speed.
- [libFuzzer](libfuzzer.md) — In-process, coverage-guided, evolutionary fuzzing engine integrated with LLVM.
