# OTA Update Security

- [fwupd](fwupd.md) — System daemon that applies signed firmware updates to peripherals and embedded Linux devices, pulling vendor metadata and payloads from the LVFS and staging…
- [Mender](mender.md) — Over-the-air software updater for Linux IoT devices with atomic updates and rollback.
- [RAUC](rauc.md) — Safe and secure firmware update framework for embedded Linux with bundle signing and A/B partitioning.
- [SUIT](suit.md) — Software Update for the Internet of Things (SUIT) working group developing manifest-based firmware update architecture.
- [SWUpdate](swupdate.md) — Linux firmware update agent with image verification and incremental updates.
- [The Update Framework (TUF)](the-update-framework-tuf.md) — Framework and specification for securing software-update systems against repository and signing-key compromise.
- [Uptane](uptane.md) — Secure software-update framework and standard for automotive systems, designed to resist compromised infrastructure and vehicle-network attacks.
