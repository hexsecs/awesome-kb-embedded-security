# Embedded Security (Awesome KB)

**Rendered site: https://hexsecs.github.io/awesome-kb-embedded-security/** —
also composed into the network site at
https://hexsecs.github.io/awesome-kb/ once registered imports build.

A living knowledge base for embedded security — firmware analysis,
reverse engineering, hardware hacking, IoT security, fuzzing, secure
boot, side-channel analysis, and SDR — in the
[OpenShelf](https://github.com/OpenNorms/openshelf) format. It grows from the
curated list [hexsecs/awesome-embedded-security](https://github.com/hexsecs/awesome-embedded-security),
which stays canon: ingest flows from the list into this KB, never the
other way around. Part of the
[Awesome KB](https://github.com/hexsecs/awesome-kb) network.

Created 2026-11-01 with a full ingest of the list (every entry as a
stub page); deepening proceeds in slices from there, following the
network's established pipeline.
